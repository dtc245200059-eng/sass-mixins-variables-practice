[Thực hành] Tạo mixins & biến để tối ưu CSS của website mẫu

Kiến trúc SASS mô-đun hóa với Variables & Mixins

Dự án này chuyển đổi đoạn mã CSS tĩnh thành kiến trúc SASS có cấu trúc phân tầng rõ ràng (Abstracts, Base, Components), sử dụng biến (Variables) để quản trị thiết kế tập trung và mixins để tái sử dụng mã hiệu quả.

Component Card

Sản Phẩm Trực Tuyến

Thẻ này kế thừa toàn bộ thuộc tính thông qua @include box-style;: màu nền trắng, padding 15px, bo tròn 10px và đổ bóng đồng nhất từ biến $box-shadow-default.

Component Card

Dịch Vụ Hỗ Trợ

Nút bên dưới áp dụng mixin @include button-style($primary-color);, tái sử dụng biến màu $primary-color: red; và padding $padding-standard: 10px 20px;.

Architecture

Tổ Chức File SCSS

Các file được tách biệt theo chuẩn 7-1 pattern thu gọn: abstracts/ chứa biến và mixins; base/ chứa typography; components/ chứa nút và thẻ.

Cấu trúc file và lệnh Import trong main.scss:

// 1. Abstracts (Biến & Mixin dùng chung)
@import "abstracts/variables";
@import "abstracts/mixins";

// 2. Base (Quy tắc nền tảng typography)
@import "base/typography";

// 3. Components (Thành phần giao diện tái sử dụng)
@import "components/buttons";
@import "components/cards";
